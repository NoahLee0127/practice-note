## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (HTML·CSS·JS 단일 파일) |
| `manifest.webmanifest` | 홈 화면 설치(앱 이름·아이콘·색상) |
| `sw.js` | 서비스워커 — 한 번 열면 인터넷 없이도 실행 |
| `icon-*.png`, `apple-touch-icon.png`, `favicon.png` | 아이콘 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 게시하도록 지정 |

## GitHub Pages 배포 순서

1. GitHub 오른쪽 위 **＋ → New repository**
   - 이름 예: `practice-diary` / 공개 범위: **Public** (무료 계정은 공개 저장소만 가능)
2. 저장소 화면에서 **Add file → Upload files** → 이 폴더의 파일 전체를 끌어다 놓기
   (`.nojekyll`은 숨김 파일이라 안 보일 수 있음. 없어도 동작함)
3. **Commit changes**
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/(root)` → **Save**
5. 몇 분 뒤 주소 확인: `https://<GitHub아이디>.github.io/<저장소이름>/`

## 수정본을 다시 올릴 때

1. `sw.js`의 `CACHE_VERSION` 숫자를 올린다 (예: `v8.0.0` → `v8.0.1`)
2. 바뀐 파일을 Upload files로 덮어 올리고 Commit
3. 사용자는 앱을 한 번 닫았다 다시 열면 새 버전이 적용됨

## v8 변경 사항 (v7 대비)

**웹 배포**
- PWA 구성: manifest, 서비스워커(오프라인 실행), 아이콘, 링크 미리보기(OG) 메타
- 브라우저에 저장소 보존 요청(`navigator.storage.persist`)

**P0**
- 기존 파일 버전 기록 옮기기 안내 배너 (기록이 없을 때 표시)
- 아이폰 Safari에서 홈 화면 설치 안내 배너 (닫으면 14일간 숨김)
- 마지막 백업 날짜 표시, 7일 이상 미백업 시 백업 권유 배너 (닫으면 3일간 숨김)
- 남아 있던 브라우저 기본 `confirm()`·`alert()` 전부 화면 안 확인창/오류 문구로 교체
  (기록 불러오기, 백업 복원, 스윙 메모 기본 문구 설정·복원·예시 되돌리기, 기본 루틴 적용·복원, 추천 배분 적용·입력 오류)
- 백업 복원 시 모든 값을 준비한 뒤 기록, 저장 실패 시 기존 값으로 전부 되돌림
- 루틴 총 공 개수 상한을 편집·불러오기 모두 2,000구로 통일

**P1**
- 연습 항목 체크박스 화면낭독기 이름(aria-label) 추가
- 항목 순서 이동 후에는 이전 `삭제 취소`를 무효화(엉뚱한 위치 복원 방지)
- 짧은 연습 시간으로 0구 항목이 생기면 필요한 최소 연습 시간 안내

**데이터 호환**
- 저장소 키·백업 형식(`version: 6`)은 v7과 동일. 기존 백업 파일 그대로 불러오기 가능.
- 새 키: `golf_diary_last_backup_v1`(마지막 백업 시각), `golf_diary_notice_dismissed_v1`(배너 닫음 기록)

## 남은 확인 사항 (실기기)

- 아이폰 Safari/Edge, 안드로이드 Chrome에서 홈 화면 설치 → 기록 저장 → 앱 종료 후 재실행
- 백업 저장(파일 앱) → 다른 기기에서 불러오기
- 비행기 모드에서 설치된 앱 실행
