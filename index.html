안드로이드 · 파일 저장 창에서 내부 저장소 폴더 선택. 지원되지 않으면 다운로드 후 파일 앱에서 이동하세요.

기기 파일은 자동으로 덮어쓰지 않습니다. 연습 후 백업을 다시 실행해 최신 파일을 보관하세요. 기기 변경 시 JSON 백업을 불러오면 됩니다.

아이폰 데이터 보존 · Safari에서 오래 열지 않으면 브라우저가 저장 데이터를 지울 수 있습니다. Safari 공유 버튼 → 홈 화면에 추가로 설치해 사용하고, 백업 파일을 정기적으로 보관하세요.

이전 버전에서 옮겨오기 · 예전에 HTML 파일로 열어 쓰던 기록은 이 웹 주소와 저장 공간이 다릅니다. 예전 파일에서 「백업 다운로드」 후, 여기서 「백업 불러오기」를 누르세요.

데이터는 이 브라우저/파일의 저장 영역에 보관됩니다. 앱·브라우저 데이터 삭제, 시크릿 모드, 파일 위치 변경 시 사라질 수 있으므로 백업 파일을 별도 보관하세요.
